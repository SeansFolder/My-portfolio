# Ralph Jean — Developer Portfolio

A dark, terminal-inspired portfolio for a graduating Computer Science student.

## Features

- Responsive design
- Terminal-style interactive UI
- Animated developer status
- Project showcase
- Tech stack
- Blank engineering timeline
- Education section
- GitHub and contact links
- GitHub Pages compatible
- No framework required

## Customize

Search the project for:

- `YOUR_USERNAME`
- `YOUR_EMAIL`
- `YOUR UNIVERSITY`
- `YOUR START YEAR`
- `Your Project`
- `Project Two`
- `Project Three`

Replace those placeholders with your actual information.

### Resume

Place your résumé at:

```text
resume.pdf
```

### GitHub Pages

1. Create a GitHub repository.
2. Upload all files.
3. Go to **Settings → Pages**.
4. Select the branch containing `index.html`.
5. Save.

Your portfolio will then be available through GitHub Pages.
